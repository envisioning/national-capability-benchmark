# Velocity review, 2026 Q3

This is the pre-launch baseline review. The velocity fixture and sandbox do not
exist yet, so the answers establish what the first live review must test.

## What did we learn about the methodology?

The placeholder rate is deliberately untested. The formula needs a base-year
choice, a treatment for negative movement, and a rule for thin or broken
momentum series before anyone can treat a velocity number as evidence.

## What did we learn about the data sources?

The proposed input is already published momentum in the country files. No
velocity output has been generated, so no source has yet been checked for
missing years, breaks, or a change in the underlying score method.

## What did we learn about the reader?

Nothing yet. There is no sandbox URL and no reader, dispute, or citation signal
to record.

## Is the layer still on track for promotion?

It is not assessable before the fixture exists. The layer remains provisional
and offline, with promotion deferred until three quarterly reviews and an
external reviewer signal exist.

## What do we need to do next quarter?

Implement issue #11, write the first fixture and sandbox, then replace this
baseline with a post-run review that names the first methodological and data
findings.
